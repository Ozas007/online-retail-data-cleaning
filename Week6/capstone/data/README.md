Place the UCI Online Retail Excel dataset in this directory as `Online+Retail.xlsx`.

The Week 6 capstone project will automatically fall back to the repository-level shared dataset at:
  `../../data/Online+Retail.xlsx`

which is populated by the Week 1–Week 4 data pipelines.

Do not commit large data files to Git; the `*.xlsx` and `*.csv` patterns here are covered by `.gitignore`.
